# React Learning Repository

A beginner-friendly React learning repository covering core concepts, hooks, API integration, and practical examples with clear explanations.

This repository is designed for students, beginners, and anyone who wants to learn React step by step.

## Why this repository?

React is a popular JavaScript library for building user interfaces. This repo helps you learn:

- React fundamentals and JSX
- Components, props, and state
- Event handling and forms
- Conditional rendering, lists, and keys
- Context API and component communication
- React hooks and custom hooks
- Routing and API calls
- Authentication and environment variables
- Loading, error handling, and performance

## Recommended learning path

1. Start with [docs/Intro.md](docs/Intro.md)
2. Set up a project with [docs/SettingUp.md](docs/SettingUp.md)
3. Learn [docs/JSX.md](docs/JSX.md) and [docs/Components.md](docs/Components.md)
4. Understand [docs/Props.md](docs/Props.md) and [docs/State.md](docs/State.md)
5. Practice event handling, forms, conditional rendering, and lists
6. Explore component communication, context, and hooks
7. Learn routing and API calls
8. Study loading, error handling, and performance

## How to clone and use this repository

1. Copy the repository URL from GitHub.
2. Clone the repository:

```bash
git clone <repository-url>
```

3. Open the repository folder:

```bash
cd React-Learning
```

4. Open the `docs` folder and read the Markdown files in the recommended order.
5. Practice the concepts and examples in your own React project.

This repository contains learning notes, not a runnable React application. You do not need to install dependencies to read the documentation.
